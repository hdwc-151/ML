# Learn Machine Learning from scratch

Chào mừng bạn đến với cuốn sách tương tác **ML & DL from scratch**.

Dự án này lưu trữ toàn bộ quá trình học tập, suy luận toán học (đạo hàm ma trận, xác suất) và mã nguồn Python/NumPy tự lập trình cho các thuật toán Học máy kinh điển.

* Mọi thuật toán đều được viết từ đầu (Zero ML Libraries trong code lõi).
* Kết quả được đối chuẩn trực tiếp với Scikit-Learn.
* Sử dụng thanh điều hướng bên trái để duyệt qua các chương và thuật toán.
