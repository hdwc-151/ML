## Prerequisites

- Linear algebra and multivariable calculus.
- Probability and statistical inference.
- Regression and classification basics.
- Familiarity with model evaluation, overfitting and regularization.
- R or Python for reproducing experiments; the mathematical text is not tied to one language.

## How to use ESL

Use ESL after an introductory ML course. It is a reference for statistical learning theory and model behavior, not a first programming tutorial. Prioritize Chapters 2–10 before selecting specialized chapters.
