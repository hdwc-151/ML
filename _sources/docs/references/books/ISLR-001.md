## Edition discipline

ISLR has multiple editions and language/programming variants. Before citing, record the exact edition and whether the example uses R or Python. The title in the table above is a family of closely related editions, not one interchangeable file.

## Chapter-level learning map

1. Introduction
2. Statistical Learning
3. Linear Regression
4. Classification
5. Resampling Methods
6. Linear Model Selection and Regularization
7. Moving Beyond Linearity
8. Tree-Based Methods

13. Multiple Testing

Check the relevant edition's official TOC for exact chapter names and ordering.

## Prerequisites

- Basic algebra and introductory statistics.
- Basic probability.
- Introductory programming in R or Python depending on edition.
- Calculus and linear algebra are helpful but the book is designed to be more accessible than ESL.
