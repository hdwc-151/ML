Phần 0: Nền tảng toán học & Tiện ích

  • Đại số Tuyến tính & Giải tích (Linear Algebra & Calculus)
  • Xác suất, MLE và MAP (Probability, Maximum Likelihood & A Posteriori)

Phần 1: Học có giám sát - Hồi quy (Regression)

  • Hồi quy tuyến tính với Phương trình chuẩn (Normal Equation)
  • Hồi quy tuyến tính với Gradient Descent (GD)
  • Hồi quy Đa thức (Polynomial Regression)
  • Khắc phục Overfitting bằng Regularization (Ridge & Lasso)

Phần 2: Học có giám sát - Phân loại (Classification)

  • Thuật toán học Perceptron (Perceptron Learning Algorithm - PLA)
  • Hồi quy Logistic (Logistic Regression)
  • Hồi quy Softmax (Đa lớp - Multinomial Logistic Regression)
  • Support Vector Machines (SVM) - Phân loại biên mềm (Soft Margin)

Phần 3: Thuật toán thực thể & Xác suất (Instance & Bayes)

  • K-Nearest Neighbors (K-NN) Classification
  • Định lý Bayes & Naive Bayes (Gaussian)

Phần 4: Cây quyết định & Học kết hợp (Ensembles)

  • Cây Quyết Định (Decision Tree - Thuật toán CART)
  • Random Forest (Rừng ngẫu nhiên - Thuật toán Ensemble)
  • Học kết hợp tuần tự (Boosting: AdaBoost & Gradient Boosting)

Phần 5: Học không giám sát (Unsupervised Learning)

  • Phân cụm K-Means (K-Means Clustering)
  • Phân cụm dựa trên mật độ (DBSCAN) & Phân cụm phân cấp (Hierarchical)
  • Phân tích Thành phần Chính (PCA) & Phân rã Giá trị Đặc dị (SVD)
  • Mô hình Hỗn hợp Gauss (GMM) & Thuật toán Kỳ vọng - Cực đại (EM)

Phần 6: Mạng Neuron & Bộ tối ưu hóa (Neural Networks)

  • Đồ thị tính toán (Computational Graph) & Lan truyền ngược (Backpropagation)
  • Mạng Nơ-ron Đa tầng (Multi-Layer Perceptron - MLP)
  • Bộ Tối Ưu Hóa (Optimizers): Từ SGD đến Adam

从零实现机器学习（Machine Learning From Scratch）#

理解数学 · 动手实现 · 实验验证

🇻🇳 Tiếng Việt · 🇬🇧 English · 🇨🇳 简体中文

本项目通过数学推导、Python/NumPy 实现、可视化和参考库对比，帮助学习经典机器学习（ML）与基础深度学习（DL）。

项目状态： 持续开发中的教育项目，包含学习 Notebook 与共享工具。各主题的完整度、API 稳定性及可复现性有所不同；本项目不是面向生产环境的 ML 框架。

项目入口#

  • 阅读在线教材（Jupyter Book）

  • 浏览 Notebook

  • 共享工具

  • 提交问题或建议

学习流程#

  1. 理解问题： 明确目标、假设、符号和适用范围。

  2. 数学推导： 梳理目标函数、公式和优化逻辑。

  3. 动手实现： 使用清晰易读的 Python/NumPy 编写。

  4. 实验探索： 可视化、调整参数、分析边界情况。

  5. 验证结果： 在适当条件下与 scikit-learn 等参考实现比较。

“从零实现”是一种学习方式，不自动保证正确、高效或数值稳定。比较时需确保假设、数据、评估方式与容差一致。

快速开始#

环境要求#

  • Python 3.9+（项目元数据要求）。

  • Conda 或 Python venv、Git 和网络连接。

CI 使用 Python 3.11，建议本地采用相同版本。

1. 克隆仓库#

git clone https://github.com/hdwc-151/ML.git
cd ML

2. 创建环境#

Conda（Python 3.13.12）：

conda env create -f environment.yml
conda activate ml-from-scratch

更新已有环境：conda env update -f environment.yml --prune。

或 venv（Python 3.13.12）：

python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS/Linux
source .venv/bin/activate

3. 安装依赖#

python -m pip install --upgrade pip
python -m pip install -e .
python -m pip install -r requirements.txt

项目声明 NumPy、Matplotlib 和 scikit-learn；requirements 还包含 Jupyter Book。依赖未完全锁定，暂不能保证环境间完全一致的复现。

4. 运行 Notebook#

jupyter notebook

打开 algorithms/notebooks 下的 Notebook。使用 JupyterLab：

python -m pip install jupyterlab
jupyter lab

5. 查看工具包#

import utils
print(utils.__all__)

工具包提供部分激活函数、损失函数、指标、距离计算与预处理。具体 API 请查看 utils/init.py 及各模块。

可复现性与验证#

  • 在全新 kernel 中依次运行 Notebook。

  • 适当记录依赖版本、随机种子和数据来源。

  • 先划分数据再拟合预处理；仅在训练集上 fit transform。

  • 检查形状、数值稳定性、边界情况和收敛性。

  • 在假设与容差一致时对比独立参考实现。

  • 不要提交大型数据集、模型 checkpoint、凭证或本地环境文件。

当前不足： 尚无全面自动化测试套件和完整依赖锁定文件。安装成功并不代表算法正确或结果可复现。

参与贡献#

  1. 为具体改动创建独立分支。

  2. 说明改动范围与数学依据。

  3. 在干净 kernel 中运行相关 Notebook，并验证修改。

  4. 在 Pull Request 中说明影响、假设与局限。

python -m pip check
python -c "import utils; print('utils import OK')"

这些基础检查不能替代测试与 Notebook 执行。
